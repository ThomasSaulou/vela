# Vela — Static Website

GitHub Pages static site for Vela.

## Images à ajouter dans `/assets/`

| Fichier | Usage | Format recommandé |
|---|---|---|
| `assets/hero.jpg` | Photo hero pleine largeur (femme avec shaker) | JPG, 1800×1200px min |
| `assets/product.png` | Photo du shaker seul sur fond transparent | PNG avec transparence |
| `assets/recipes.jpg` | Photo recettes (personne préparant un shake) | JPG, 900×600px min |

## Déploiement GitHub Pages

1. Push ce dossier sur un repo GitHub
2. Settings → Pages → Source: `main` / `root`
3. Le site est live sur `https://<username>.github.io/<repo>/`
